PLACEHOLDER ICONS — MUST BE REPLACED BEFORE PRODUCTION
=======================================================

The files pwa-192x192.png and pwa-512x512.png in this directory are
1×1 pixel placeholder images used only to allow the build to compile.

Before going live, replace them with:
  - pwa-192x192.png  → 192×192 px PNG icon (restaurant logo)
  - pwa-512x512.png  → 512×512 px PNG icon (restaurant logo)

These icons are displayed:
  - On the device home screen when users install the PWA
  - In the browser's tab / splash screen
  - On Android/iOS install prompts

Recommended tool: https://realfavicongenerator.net/
